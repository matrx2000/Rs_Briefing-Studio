About R's Briefing Studio v1.1.0

R's Briefing Studio turns proposals into beautifully designed, two-page briefings. The output is built to be read in 90 seconds (page 1) with full context available on demand (page 2).

What's new in v1.1.0

Markdown export mode. Both editors now have a Print / Markdown toggle in the chrome. In Markdown mode, the preview pane swaps from the A4 sheets to a rendered wiki-style view, and the primary button becomes Export .md. The output is a single .md file using the standard wiki macro set: info / note / warning panels, expand/collapse blocks, table of contents, status badges, and tables for two-column layouts (pros vs. cons, metric vs. visual, cost & value, trade-offs, risks). Drop it into any wiki page that supports those macros.

Why it exists

This app is not here to add another document to your pile. It exists to make the way you communicate ideas, issues, and opportunities clearer — by formalizing a format that breaks each one into small, digestible chunks. The result is a single shared artefact you and your teammates can sync on in minutes, without ambiguity, instead of trading long Word docs or sitting through forty-slide decks.

Each field has a discipline behind it. Filling them in forces you to commit to the decision, the headline number, the trade-offs, and what you actually know vs. what you’re guessing — so the people reading your briefing arrive at the same picture you have.

Two report types

Executive Level Reporting — for decision-makers. Bottom line, headline metric, 5 Ws + H, pros / cons, timeline, the ask.

Engineering Reporting — for technical reviewers. Proposal, effort, what changes, cost & value, trade-offs, risks, open questions, the ask.

How it works

Fill the structured form on the left. The right pane updates live. Export the result as a PDF (A4 or A3 portrait), as wiki-flavoured Markdown, or save the project as a JSON file (image included as base64) to keep working on it later.

If text overflows, that’s a feature

The app never truncates or auto-shrinks. Spillover is the app telling you the idea isn’t tight enough yet — cut adjectives, pick the one number that matters, and edit until everything fits on two pages.
